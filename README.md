# 授業の復習テスト

スマートフォン向けの静的Webテスト。アカウント登録不要で、タップ回答、ヒントつき再挑戦、各問の解説、得点・正答率・誤答一覧、解き直しに対応します。得点は最初の回答で集計し、各問1点です。中断した場合は最後に回答した問題の次から再開します。記録はブラウザ内のみで、保護者への結果送信はありません。

## 現在の状態

授業資料が作業環境に同期されていないため、問題一覧は空です。架空の授業問題は登録していません。

## PLAUD要約から追加する

次の依頼文と授業要約をCodexに渡してください。

> この授業要約から、web-testの既存形式で復習テストを追加してください。授業内容を最優先し、基礎→標準→定期テストレベルの順に、理解を問う問題も含めてください。各問に選択肢・正解・ヒント・解説・復習ポイントを用意してください。重要な文字起こしの誤変換は不明なら確認し、補足は授業内容と区別してください。data/catalog.jsonにも登録し、検証後GitHub Pagesを更新してください。授業要約の原文や個人情報は公開ファイルに含めないでください。

1. `tools/test-template.json`を参考に、`data/英数字のID.json`を追加します。正解の`answer`は0から始まる選択肢の番号です。問題ごとの`id`は一意にします。
2. `data/catalog.json`の`tests`に以下の形式で1件追加します。

```json
{"id":"subject-yyyymmdd-topic","subject":"教科名","title":"授業テーマ","description":"学習範囲","file":"subject-yyyymmdd-topic.json"}
```

3. `python3 tools/validate.py`で検証します。設問や選択肢を変更したら`version`を増やして古い回答記録と区別します。
4. mainブランチにコミット・プッシュするとGitHub ActionsがPagesを更新します。

一覧URLの末尾に`?test=テストID`を付けると、その授業の開始画面へ直接移動できます。LINEでこのURLを共有してください。

## ローカル表示

このフォルダで`python3 -m http.server 8000`を実行し、`http://localhost:8000`を開きます。

## 公開の仕組み

GitHub PagesのSourceは「GitHub Actions」を使用します。公開対象は`index.html`、`app.js`、`style.css`、`data/*.json`だけです。原文・録音・プリントはこのリポジトリに追加しません。問題と正解は公開データです。ブラウザの通常画面では回答前に正解を表示しません。

同じ問題の解き直しは復習用です。理解の定着確認には、後日、数字や聞き方を変えた類題を追加してください。
